## 📦 How to Run Locally

1. Clone the repository using SSH:
   ```bash
   git clone git@github.com:tolikhere/frontend-mentor.git
   ```
2. Navigate into the root directory:
   ```bash
   cd frontend-mentor
   ```
3. Open any challenge subfolder and launch the `index.html` file using your web browser or a development tool like **Live Server**.
